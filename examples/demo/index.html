site-narrator / demo

A page that reads itself

Five paragraphs, five small sound files, no speech service. Press Listen on any paragraph, or hear them all in order.

Ready.

  1. This page has a voice, and the voice was recorded before you arrived. Nothing is generated while you listen, and nothing you do here is sent to a speech service.

  2. Each paragraph was turned into a small sound file on the author's own computer. The file is named after a fingerprint of the paragraph's text, so the page can find it without keeping a list.

  3. If a paragraph is edited, its fingerprint changes and the old file no longer matches. The paragraph stays silent until it is recorded again, which takes one command.

  4. Some things are written one way and said another. Here the recorder spells out CSS, reads 20 °C as a temperature, and knows that 3 × 4 = 12.

  5. The voice is computer-generated. It comes from Kokoro, an open text-to-speech model, and you can switch it off with the button at the top of the page.

The voice on this page is computer-generated (Kokoro text-to-speech). With the voice off, the highlight still moves through the paragraphs at reading speed.
